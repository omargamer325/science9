# مختبر الملفوف — نسخة GitHub Pages

الموقع static. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يظهر `index.html` مباشرة في قائمة ملفات المستودع، ويظل مجلد `videos` بجانبه.

## تفعيل GitHub Pages

1. فك ضغط ملف الحزمة على جهازك.
2. افتح مستودع GitHub واضغط **Add file → Upload files**.
3. ارفع محتويات المجلد، لا ترفع ملف ZIP وحده ولا تضع الملفات داخل مجلد فرعي.
4. اضغط **Commit changes**.
5. افتح **Settings → Pages**، واختر **Deploy from a branch** ثم فرع `main` والمجلد `/(root)`، واحفظ.
6. تأكد أن اسم الملف `index.html` بالأحرف الصغيرة.

ملف `.nojekyll` يطلب من GitHub Pages نشر الملفات كما هي. ملف `_headers` خاص بـNetlify؛ GitHub Pages لا يطبّق منه ترويسات أمان.

## حماية مفاتيح API

هذه النسخة لا تتصل حاليًا بـAPI أو Firebase. لا تضع مفاتيح أو كلمات مرور داخل `index.html` أو JavaScript. ملف `.gitignore` يقلل احتمال رفع ملفات الأسرار المحلية بالخطأ، لكنه لا يزيل سرًا سبق رفعه ولا يحمي مفتاحًا مكتوبًا داخل كود المتصفح. عند تحديد مزود API، خزّن السر في بيئة خادمية مثل Netlify Functions.
